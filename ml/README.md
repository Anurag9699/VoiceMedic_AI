# Machine Learning (ML) Directory

This directory is designated for future Machine Learning pipelines, models, and scripts for the **Voice-Controlled Payment System**, as detailed in the Project Requirements Document (PRD):

- **ASR (Automatic Speech Recognition)**: Speech-to-text models, acoustic feature extraction (Log-Mel spectrograms), and tokenization.
- **Speaker Verification**: Voice embedding extraction (e.g. ECAPA-TDNN / x-vector) and cosine similarity matching.
- **Command Understanding**: Parsing payment intent, recipient, and amount from transcripts.

*Note: In accordance with the initial project scaffolding phase, no ML models are loaded or trained yet.*
