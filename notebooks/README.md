# Jupyter & Research Notebooks

This folder will store exploratory data analysis (EDA), speech data inspection, and experimental notebooks for the **Voice-Controlled Payment System**:

- `01_audio_preprocessing_eda.ipynb`: Waveform analysis, audio normalization, silence trimming, and SNR inspection.
- `02_asr_baseline_exploration.ipynb`: Baseline ASR transcription and WER/CER benchmark experiments.
- `03_speaker_embedding_experiments.ipynb`: Voice embedding extraction and similarity threshold calibration.

*Note: Notebooks will be added in upcoming project phases.*
